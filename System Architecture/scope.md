# The Project Purpose
The Smart Insulin Pump (SIP) App aims to support diabetes management by providing a secure and user-friendly mobile interface that connects with a smart insulin pump and an external continuous glucose monitoring (CGM) sensor. 
The app enables patients and their caregiver to view real-time glucose data, receive AI-based glucose predictions, and get personalized bolus dosage suggestions that require user confirmation before delivery. 
The insulin pump continuously handles basal insulin delivery, while the app allows supervised adjustments and provides caregiver and healthcare staff access for monitoring. 
The purpose of this project is to enhance safety, visibility, and decision-making in insulin therapy through an integrated and accessible app.

# The Scope Description
### Inside of Scope:
These are features you will implement in the first iteration (MVP):

- Real-time glucose level monitoring (using hypothetical CGM data)
- Caregiver access (view-only monitoring).
- Alert notifications (high/low glucose alerts, connection issues).
- Carb intake input interface.
- The caregiver interface (same UI structure as patient interface, with multiple dependents supported).
- Appwrite backend setup (authentication, database, APIs).
- Basic user profile management (patient + caregiver).
- Basic history for glucose readings (limited).
- Simple dashboard UI (current glucose, trend arrow, last readings, emergency button).

### Future Scope:
These are features planned for later versions (NOT in MVP but part of long-term vision):

- Mobile app integration with the insulin pump.
- Integration with CGM sensor brands.
- Remote control of the insulin pump (manual bolus confirmation, basal adjustments).
- Monitoring device status (pump battery, CGM battery, insulin reservoir, connectivity).
- Glucose event prediction (AI-based forecasting).
- Healthcare staff access (clinician dashboard).
- Full historical logs (insulin intake, carb intake, alerts, average glucose, TIR).
- Emergency button to call 997 with automatic location-sharing.
- Direct doctor/patient communication: messages and calls.
- Multi-device syncing (phone, tablet, caregiver devices).
- Automatic analysis reports (weekly/monthly summaries).
- Cloud backup & multi-user account recovery.
- Advanced data visualization (charts, trends, insights).

### Outside of Scope:
- Official medical certification (FDA, CE, SFDA).
- Pump hardware manufacturing.
- Clinical trials.
- Wearable technology development (smartwatches, smart patches).
